# Анимированные подсказки движения камеры

В экранах камеры добавлен векторный пример с телефоном и стрелками. Он показывает
жест рядом с текущей инструкцией и не закрывает настоящий прицел.

| Состояние | Что показывает подсказка |
|---|---|
| Поиск и подготовка поверхности | Телефон плавно перемещается влево-вправо между двумя положениями; стрелки показывают направление. |
| Резкое движение | Телефон неподвижен, рядом знак паузы. |
| Возврат к ранее отсканированному участку | Телефон возвращается к пунктирному силуэту. Это пример жеста, а не вычисленное направление к объекту. |
| Недостаток света | Рядом с телефоном мягко подсвечивается солнце. |
| Недостаток деталей | Движение телефона над участком с отмеченными деталями. |
| Нет поверхности под прицелом | Прицел внутри изображения телефона совмещается с точкой. |
| Изменение высоты камерой | Вертикальные стрелки и движущийся уровень показывают движение прицела вверх-вниз. |
| Подготовка завершена | Статичная галочка: движение больше не требуется, можно начинать замер. |

После начала замера на валидной поверхности обучающая анимация скрывается. Причина
сбоя камеры имеет приоритет перед подсказкой высоты. При закрытии камеры, открытии
справки или уходе приложения в фон повторение останавливается. Системное отключение
анимаций поддерживается средствами Compose; стрелки и текст остаются видимыми.

Реализация: `CameraMotionCue.kt` выбирает пример по состоянию, `CameraMotionGuide.kt`
рисует его в Canvas. Значение анимации читается при рисовании, без обновления всего
экрана на каждом кадре. Внешних библиотек, растровых ресурсов и сетевых запросов нет.
Подписи используют общие ресурсы локализации приложения.

Артефакты проверки находятся в `build/camera-motion/`. Эти подсказки объясняют жесты;
они не изменяют алгоритм распознавания поверхностей или допустимость установки точек.
