# Проверка интерактивного макета

21 сентября 2026. Проверен локальный макет будущих режимов Rulivo в браузере. Android-реализация не менялась; Android-сборка и физическая точность не проверялись в этой задаче.

| Сценарий | Наблюдаемый результат |
| --- | --- |
| Предмет 60 × 40 × 35 см | 84 л; после смены единиц — 0,084 м³ |
| Высота предмета изменена с 35 до 70 см | Объём удваивается: 0,168 м³ |
| Нулевая высота | Ошибка ввода, сохранение недоступно |
| Комната 4,2 × 3,6 × 2,7 м | Отображается 40,8 м³; площадь 15,1 м²; периметр 15,6 м |
| Высота комнаты неизвестна | Только площадь; поле высоты выключено, объём отсутствует |
| Г-комната 4 × 4 м с вырезом 2 × 2 м и высотой 2,7 м | 32,4 м³; 12 м²; периметр 16 м |
| Вырез равен внешней длине комнаты | Ошибка геометрии |
| Покрытие для 15,12 м², запас 10%, упаковка 2,2 м² | 8 упаковок; 16,63 м² с запасом; 17,6 м² в упаковках |
| Ниша 100 × 60 × 80 см, предмет 98 × 55 × 75 см, зазор 1 см с каждой стороны | «Впритык»; остатки 0, 3 и 3 см |
| Поворот этого предмета на основании на 90° | «Не помещается»; по глубине не хватает 40 см |
| После сохранения изменены размеры | Сохранённый пример остаётся 0,084 м³; текущий меняется до 168 л |
| Ширина макета 320 px | Горизонтального переполнения нет; поля и результаты доступны |
| JavaScript | Синтаксис валиден; ошибок в консоли в проверенных сценариях нет |

Макет показывает выбор режима, редактирование демонстрационных размеров, расчёт и временное сохранение примеров. Установка AR-точек, произвольный контур, постоянное хранилище, цилиндр, свободный объём и экспорт описаны в [спецификации](MEASUREMENT_MODES.md), но в макете не реализованы.
